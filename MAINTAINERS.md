# Maintainer notes

## Versioning convention

The version lives at the very top of `README.md`, directly under the title, as
an `<h5>` line:

```
# Net-Peekier
##### v1.0.11
```

**On every update, bump this version** (patch bump for fixes/small features,
e.g. `v1.0.11` → `v1.0.12`). The version is owned by the project README — keep
it in sync whenever the README is regenerated, and never drop the line.

Current version: **v1.0.19**
